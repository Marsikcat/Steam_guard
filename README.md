# Steam Guard для Windows

Неофициальный клиент для нескольких аккаунтов Steam. Он генерирует коды входа офлайн и позволяет вручную подтверждать запросы Steam. Интерфейс и клиент написаны на C# с использованием .NET Framework. Сторонний исполняемый файл для работы не нужен.

## Сборка

На Windows 10 или 11 с .NET Framework 4.8 открой PowerShell в папке репозитория и запусти:

```powershell
.\Build.ps1
```

Портативный EXE появится в корне репозитория как `buildSteamGuard.exe`. Права администратора для сборки и запуска не требуются. `.Build.ps1 -Check` также запускает проверки с тестовыми данными. Исполняемый файл не подписан.

## Перенос действующего Steam Guard

1. Нажми **Подключить аккаунт**. В одном окне можно ввести логин и пароль или отсканировать QR-код в разделе Steam Guard приложения Steam Mobile. При входе по QR проверь данные запроса и подтверди вход на телефоне.
2. Нажми **Отправить SMS**. Steam использует номер, привязанный к аккаунту.
3. Введи код от Steam, проверь предупреждение о переносе и только затем нажми **Перенести**.
4. Запиши новый код восстановления. Повтори шаги для других аккаунтов, которые хочешь перенести.

При переносе Steam заменяет аутентификатор для выбранного аккаунта. Старый телефон перестанет выдавать действительные коды для него. Valve указывает, что обмены и Торговая площадка ограничиваются на два дня после переноса. [Справка Steam](https://help.steampowered.com/ru/faqs/view/7EFD-3CAE-64D3-1C31)

Для уже имеющихся файлов или секретов доступны отдельные варианты добавления через меню **Другие способы**. Импортированный таким образом аккаунт позволяет генерировать коды входа.

## Хранение и запросы

Пароль аккаунта используется при входе и не записывается на диск. Секреты аутентификатора, код восстановления и токен обновления хранятся в зашифрованном файле `%LOCALAPPDATA%LocalSteamGuardaccounts.dat`. Шифрование DPAPI привязано к текущему профилю Windows. Для перехода на другое устройство используй перенос Steam Guard, а для восстановления доступа храни код восстановления отдельно.

Коды вычисляются из системного времени Windows. Проверка входов и других запросов Steam запускается вручную из окна **Подтверждения**.

Сетевые функции используют недокументированные интерфейсы Steam. Совместимость может измениться на стороне Steam. Проверки сборки используют смоделированные ответы. Реальный перенос на аккаунте не проверен.

Описание формата сообщений [SteamDatabase Protobufs](https://github.com/SteamDatabase/Protobufs).
